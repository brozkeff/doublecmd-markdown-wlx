# Archived v0.1.x implementation

This directory preserves the initial v0.1.x implementation of the Markdown
WLX plugin. It was written in Free Pascal with Lazarus, matching the language
used by Double Commander itself.

The Pascal/Lazarus approach was later found unsuitable for this standalone
plugin. The project was completely rewritten in Rust for v0.2.0 and later
versions; the current Qt5 plugin and build instructions are in the repository
root. Files in this directory are kept for historical reference and manual
inspection, and are no longer part of the current build.
